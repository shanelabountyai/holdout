Install the snippet

Your site's server holds the API key; the browser never does. The server renders the running experiments into the page, the snippet assigns each visitor with the same function the server checks exposures with, and your server relays its events to Holdout.

  1. 1 · Create an API key with read and ingest

    Owners and admins do this in Settings → API keys. Keep the key on your server. Open API keys Members see: "An owner or admin creates API keys."

  2. 2 · On your server: load the config, then relay events

    import { HoldoutServer } from './holdout/server';
const holdout = new HoldoutServer({ baseUrl: '{{origin}}', apiKey: process.env.HOLDOUT_KEY });
await holdout.refresh();               // GET /api/v1/experiments (read)
const experiments = holdout.experiments(); // render into the page for the snippet
// in your relay route (same site as the page), with the visitor id from your own cookie:
holdout.enqueue(events);
await holdout.flush();                 // POST /api/v1/ingest (ingest), up to 500 events

  3. 3 · In the page: the snippet

    <script src="/holdout.js"></script>
<script>
  Holdout.init({ experiments: /* rendered by your server */, unitId: visitorId, endpoint: '/collect' });
  const v = Holdout.variant('{{key}}');   // logs one exposure
  // on purchase: Holdout.track('{{event}}');
</script>
    holdout.js is built from the repo by npm run sdk:build ([n] bytes).

Keys to use: running experiments

ExperimentKeyVariants, in bucket orderMetric event
[name][key][control] [w]% · [treatment] [w]%[event]

Empty: "Nothing is running. Drafts are not served; start one from its page."
